# Ejercicio Kotlin de consola

Este ejercicio **no es una app Android** y no se ejecuta con el botón Run de Android Studio.

Abre una terminal en esta carpeta y ejecuta:

```powershell
kotlinc Ejercicio.kt -include-runtime -d ejercicio.jar
java -jar ejercicio.jar
```

Lee `ENUNCIADO.txt` y compara la salida con lo que pide.
